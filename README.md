# Secure Firmware Update Engine（本地模拟）

一个无外部服务、无真实密钥材料的本地固件安全更新引擎模拟，覆盖：

- **签名与完整性校验**：Ed25519（种子确定性派生的测试钥）+ SHA-256，固定顺序校验，
  失败给出可区分错误码（未知钥/过期/未生效/用途不符/坏签名/载荷被篡改）。
- **版本推进与防回滚**：严格版本递增；降级、同版本重放、型号/目标不符分别拒绝；
  轮换期多钥并存时只按包内 KeyID 做唯一确定性判定，不静默择优。
- **连续升级**：同一台设备可从出厂版本一轮轮往上装（v1→v2→v3→…），每轮健康确认后
  直接装下一版，无需回滚/清空/重新初始化；轮换窗口（新旧钥并存）内结论依旧唯一确定。
- **两版本容量上限**：设备始终只保留“当前运行版本 + 上一个可回滚的已知良好版本”两个版本；
  反复升级/回滚不堆积、不拖慢后续升级；覆盖旧版本中途掉电或写失败，重启仍停在可启动的
  已知良好版本。
- **暂存/激活/确认/回滚**：A/B 双槽 + 原子启动指针，写入中断、激活前掉电、试运行失败
  均保证设备停留在已知良好版本；重复操作幂等；显式与自动回滚最终状态一致。确认后仍可一键
  回退到保留的上一已知良好版本。
- **并发与重复提交**：同一设备上两个升级请求几乎同时到达时恰有一个生效，另一个拿到稳定的
  `update_busy` 拒绝；库入口（多 goroutine）与 CLI 入口（多进程）结论完全一致；同一份更新
  重复提交永远幂等。

详细语义、容量下限、并发约定、密钥轮换/回滚规则与本地验证步骤见
[docs/DESIGN.md](docs/DESIGN.md)。

快速开始：

```bash
go test -race -count=1 ./... -v
go run ./cmd/fwupdate init
```
